command : cc
________________________________________________________________________________
DESCRIPTION:
Compiles C-like source text into a native executable inside SystemZero.

    > cc hello.sz hello
    > hello

The build installs hello.sz, files.sz, draw.sz, and threads.sz as source examples.
Use touch to create a source file, edit to write it, Ctrl+S to save, and Escape
to leave the editor. Source and output must have different names.

Supported: int, char, void, pointers, arrays, functions, variables, strings,
if/else, while, break/continue, return, arithmetic, and short-circuit logic.
Kernel services are built in: print, print_dec, print_hex, putchar, newline,
clear, set_color, get_color, screen_rows, screen_columns, put_text, put_cell,
begin_update, end_update, draw_pixel, draw_line, alloc, memcpy, memset, strlen,
readline, getchar, file_size, file_read, file_write, file_delete, file_create,
sleep, execute, thread_start, thread_join, thread_yield, thread_sleep, thread_id,
thread_count, mutex_create, mutex_lock, mutex_unlock, clock_time, status_position,
and settings_apply. File sizes, read counts, and offsets are in bytes.

    int main() {
        print("Hello from SystemZero!\n");
        return 0;
    }

Source/output are on the selected drive. The shell searches that drive first,
then the system drive for bundled commands. Output is replaced only after a
successful compile; errors show filename:line:column and return status 1.
The first version has no includes, floating point, structs, for/switch,
general function-pointer declarations, variadic calls, or separate object/library linking.
Pass an int worker(int argument) function name to thread_start to create a worker.
Use mutexes for shared data; the command waits for its workers before exiting.
Source limit: 64 KiB. Executable limit: 256 KiB.
Use view language.txt for the full syntax and API reference.


command : settings
________________________________________________________________________________
DESCRIPTION:
Graphical clock, status bar, and terminal color settings.

    > settings

Tab/Shift+Tab selects a field. Arrow keys adjust values and navigate the color
palettes; digits enter hours/minutes/seconds. Enter saves and Escape cancels.
The clock uses 24-hour HH:MM:SS. The status bar can sit at the top or bottom.
Foreground/background palettes show all 16 colors with a text preview.
Settings and the clock offset are saved in systemzero.cfg on the system drive.
The previous console is restored when you close settings.


command : cls
________________________________________________________________________________
DESCRIPTION:
A program that clears the screen (yes, only that).

EXAMPLE USAGE:

    > cls

will clear the screen.


command : color
________________________________________________________________________________
DESCRIPTION:
A program that allows you to change the terminal color scheme.

OPTIONS:

    > color [0-15] [0-15]

the first parameter is the background,
the second parameter is the foreground.

VGA COLOR TRANSLATIONS:
0  - black
1  - blue
2  - green
3  - cyan
4  - red
5  - magenta
6  - brown
7  - white
8  - gray
9  - light blue
10 - light green
11 - light cyan
12 - light red
13 - light magenta
14 - yellow
15 - bright white

EXAMPLE USAGE:

    > color 1 15

will bring you back to the default color scheme (white on blue).


command : copy
________________________________________________________________________________
DESCRIPTION:
A program that allows you to copy files both within a single drive or across
multiple drives.

OPTIONS:

    > copy x:<source_file> y:<destination_file>

will copy source_file located on the drive with index of x into a file called
destination_file which will be located on drive with index of y.

EXAMPLE USAGE:

    > copy 0:LICENSE 1:LICENSE_copy

will copy LICENSE from IDE0 to LICENSE_copy on IDE1.


command : del
________________________________________________________________________________
DESCRIPTION:
A program that deletes a file.

EXAMPLE USAGE:

    > del LICENSE

will delete the LICENSE file.


command : drive
________________________________________________________________________________
DESCRIPTION:
A program that changes your selected drive.

EXAMPLE USAGE:

    > drive 2

will set your drive to IDE2.


command : drives
________________________________________________________________________________
DESCRIPTION:
A program that lets you view your available drives.

EXAMPLE USAGE:

    > drives

will list all your possible drives, they can have a status of 'absent' or
'exists'.


command : edit
________________________________________________________________________________
DESCRIPTION:
A program that lets you edit text files.

EXAMPLE USAGE:

    > edit LICENSE

will open LICENSE for editing.

KEYBINDINGS:
ctrl+s    save
ctrl+r    reset cursor to top left
esc       quit
arrows    move through visual lines, preserving column with up/down
home/end  move to the start/end of the visual line
ctrl+home/ctrl+end  move to the start/end of the file
pgup      move up one page
pgdn      move down one page
tab       insert a tab (displayed with four-column tab stops)
backspace/delete  remove the previous/current character

The cursor stays visible as you type and move. Only changed screen cells are
repainted. A modified marker remains until the file is saved. Escape exits
without saving unsaved changes.


command : format
________________________________________________________________________________
DESCRIPTION:
A program that formats the selected drive with ESFS 
(will not remove the SystemZero kernel if it is on the drive).

!!! NOTE !!! 
Use this carefully! It will wipe all your files on that drive!

EXAMPLE USAGE:

    IDE3> format

will format IDE3 with ESFS.


command : hexedit
________________________________________________________________________________
DESCRIPTION:
A program that lets you edit files in hex mode.

EXAMPLE USAGE:

    > hexedit LICENSE

will open LICENSE for editing in hex mode.
The display shows 16 bytes per row, an eight-digit offset, and an ASCII column.
Arrows move the selected byte; Page Up/Down moves a full page. The c and i keys
change or insert a byte, d/Delete removes it, and Backspace removes the previous
byte. Press w or Ctrl+S to save. Escape cancels byte entry or exits the editor.
Home/End move within a row; Ctrl+Home/Ctrl+End move to the file boundaries.


command : list
________________________________________________________________________________
DESCRIPTION:
A program that lists all the files on the selected drive and show their size.

EXAMPLE USAGE:

    IDE0> list

will list all files on IDE0 and show their size.


command : read
________________________________________________________________________________
DESCRIPTION:
A program that will dump all the text from a file onto the screen.

EXAMPLE USAGE:

    > read LICENSE

dumps all text from LICENSE onto the screen (unreadable).


command : touch
________________________________________________________________________________
DESCRIPTION:
A program that will create a file with the specified name (if that file
doesn't already exist).

EXAMPLE USAGE:

    > touch test.txt

will create an empty file called test.txt


command : view
________________________________________________________________________________
DESCRIPTION:
A program that will allow you to read a file with scrolling.

OPTIONS:

    > view LICENSE

will view LICENSE from the start.

    > view LICENSE 10

will view LICENSE from the 10th line.

KEYBINDINGS:
pgup    scroll up
pgdn    scroll down

Thanks for reading the SystemZero manual.
